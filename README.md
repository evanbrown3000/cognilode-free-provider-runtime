# Cognilode free provider runner — retired reference

This repository is retained only as historical implementation/reference material for the earlier zero-paid ephemeral provider lane.

It is **not** an active Cognilode runtime, scheduler, corpus owner, provider sender, or fallback. GitHub Actions execution and the old `publish_and_dispatch.py` bootstrap are retired because the selected Cognilode design must not depend on GitHub Actions or create a second conversation corpus.

Reusable runner code remains here only for source archaeology and selective reuse inside the existing B4PT0R/Framework/Harness/SDK ownership model. Current execution, memory, Operator, Company/TaskFlow, provider-account ownership, and corpus identity must come from the selected shared system and the user-authored design target rather than this repository.
